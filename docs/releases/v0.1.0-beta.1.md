# ClipForge 0.1.0 Beta 1

The first Windows beta of ClipForge: keep reusable text in named letter registers
and recover recent clipboard entries from a tray-based picker.

## Included

- 26 named text registers (A–Z) and up to 100 recent clipboard entries.
- Windows history now captures PNG/DIB images, file references, spreadsheet cells, and memory-backed binary formats. Selecting an entry restores its captured formats, including with keyboard navigation.
- Thumbnails, table previews, file labels, and Details with format names, file paths, and a short hex sample.
- Native copy/paste shortcuts and configurable hotkeys with conflict detection.
- Tray access, inline multiline editing, and drag/drop between history and registers.
- **Clear history** in the History panel removes recent copies while preserving registers and the current clipboard. **Clear registers** in the Registers panel clears register text and names while preserving history and the current clipboard. **Clear ALL** at the bottom clears both panels and the host clipboard.
- Updated README screenshots show mixed sample clipboard data, panel controls, inline editing, and binary details.
- The new ClipForge icon and illustrated quick-start documentation.

## Windows download

Download `clipforge.exe` and run it from a permanent folder. Microsoft WebView2
Runtime is required. Click the tray icon or press **Ctrl+Alt+Space** to open the
picker. No installer is required.

To save selected text to X, press **Ctrl+Alt+C**, release C, then press X. To paste
it, use **Ctrl+Alt+V**, release V, then X. Release modifiers to allow native
Copy/Paste. Customize the shortcuts with the gear button.

## Beta limitations

- Registers are text-only, up to 1 MiB per entry. Windows rich entries have a 32 MiB capture limit and history has a 128 MiB payload budget. Registers and history disappear on exit;
  only hotkeys persist.
- Windows input injection cannot reach elevated applications from a lower-integrity process.
- VM clipboard sharing requires guest tools. macOS/Linux binaries are not included
  in this beta, and their runtime behavior remains unverified.
- File entries reference existing files rather than embedding their contents; restored file entries use copy semantics. PDFs show filenames, not rendered first pages. Process-specific OLE, virtual files, and GDI/metafile handles are excluded; full Excel/OLE fidelity is not guaranteed.
- Automated checks passed: 30 Rust unit tests, frontend tests, seven clipboard/status integration tests, native rich-format round trips, Clippy, browser layout checks, and both desktop startup checks. Manual custom-hotkey and tray-click
  behavior still need broader beta testing.

Report issues with your Windows version, reproduction steps, and expected behavior
at https://github.com/Pline-0x8/ClipForge/issues.
